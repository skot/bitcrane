![bitcrane logo](doc/bitcrane.png "Logo")

Bitcrane can fully control a Bitmain Antminer over a single USB connection.

- CERN Open Hardware License (OHL) v2
- [KiCad](https://kicad.org) design files
- Based on the Raspberry Pi RP2040
- Support for 3 Antminer hashboards
- Support for 4 fans with your choice of 1x4 or 2x2 connectors
- Controls Antminer S19/S21 style PSUs
- Bitcrane is powered by 5V from the USB-C connector
	- Attached fans are powered by standard Antminer 2x3 12V controlboard power
